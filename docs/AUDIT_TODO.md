# Аудит и приоритизированный TODO

Сводный результат аудита пятью экспертами (фронтенд-архитектор, лингвист греческого,
студент-новичок, методолог CEFR/SLA, экзаменатор ΚΕΓ A1/A2) + объективные метрики.
Отсортировано от самого важного к наименее важному. Помечено, кто из экспертов поднял пункт.

Текущее состояние: 29 тестов зелёные, ~8000 строк JS, греческий 9/10, контент сильный.
Главный вывод: **отличный тренажёр рецепции и грамматики (~75% подготовки к A2),
но провисают продуктивные навыки (письмо/говорение с обратной связью), аудирование
связной речи и удержание мотивации.**

## P0 — критично (бьёт по результату: сдача экзамена / удержание ученика)

1. ✅ **СДЕЛАНО.** **Конфликт «12 новых слов/день (SRS) vs ~15-17 в колоде дня (Путь)».** `NEW_PER_DAY=12`
   (srs.js:8), колода ~17, UI обещает «~15», счётчик на главной «12 − newToday»
   (app.js:338). Ученик не понимает, почему слова «не пускаются». _[студент, методолог]_
   → Согласовать: либо лимит = размеру колоды дня, либо явно объяснить «сегодня N новых».

2. **✅ Письмо-продукция и говорение не входят в зачёт и без обратной связи.** Открытое
   письмо/о-себе/диалоги работают «покажи образец», сверка на глаз; в buildExam письмо =
   выбор порядка + набор одного известного предложения. На реальном ΚΕΓ письмо = анкета +
   открытка/записка 20-40 слов, оцениваемые человеком. _[экзаменатор, методолог]_
   → Добавить guided-письмо с чек-листом обязательных элементов; включить продукцию в экзамен.

3. **✅ Заполнение официальной формы/анкеты (αίτηση) не тренируется вообще.** Якорное задание
   кипрского экзамена. _[экзаменатор]_
   → Задание «заполни анкету» с реальными графами (Επώνυμο, Όνομα, Ημ. γέννησης, Διεύθυνση…).

4. **✅ Аудирование связной речи отсутствует.** «Аудио» = отдельные слова/фразы через TTS;
   на экзамене — диалоги/объявления. SPEAKING_DIALOGS идеально подходят как источник. _[экзаменатор, методолог]_
   → Listening-задание: прослушать диалог из 2 голосов/объявление → 2-3 вопроса.

5. **✅ Чтение без проверки понимания.** 140 текстов = только тап-перевод, вопросы лишь у 25
   экзаменационных. Input не верифицируется (нарушение «понятного ввода»). _[методолог, экзаменатор]_
   → Добавить 2-3 вопроса на понимание к текстам трека.
