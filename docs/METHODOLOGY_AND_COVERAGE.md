# Методология и покрытие

> Этот документ обновляется при каждом апдейте контента.
> Цифры покрытия пересчитываются скриптом: `python3 tools/coverage.py`.

## Методология

Подход синтезирован из исследований по освоению языка и согласован с CEFR:

1. **Алфавит в первую очередь** — узнавание букв и буквосочетаний (визуал + звук).
2. **Интервальные повторения (SRS, SM-2)** — ядро удержания словаря; тренировка
   тем тоже пишется в прогресс.
3. **Понятный ввод (comprehensible input)** — graded-тексты A0→A1 с тап-переводом
   и озвучкой.
4. **Продукция** — письмо (конструктор/пропуски/о себе/текст из слов) и речь
   (произношение с распознаванием).
5. **Тематическая подача + 4 навыка** экзамена (чтение, аудио, письмо, говорение).
6. **Самопроверка** — пробные экзамены в формате реального теста.

Принцип синергии: слова из словаря должны встречаться в текстах/упражнениях
(контекст → удержание), поэтому новые слова сопровождаются текстами и заданиями.

## Эталон A1

Официальный ориентир — **Κέντρο Ελληνικής Γλώσσας (ΚΕΓ)**, экзамен
«Πιστοποίηση Ελληνομάθειας». Закрытого word-list нет; ближайший официальный
источник — глоссарий учебника **ΚΛΙΚ στα ελληνικά Α1** (~563 леммы в нашей
выгрузке; реальное ядро ~800–1000). Грамматика A1 (по офиц. «Πίνακες Γραμματικής»):
наст./прош. (αόριστος)/буд. простое, να + сослагательное, повелительное, 3 падежа,
предлоги σε/από/με/για/μετά/μέχρι/παρά, союзы και/αλλά/ή/γιατί/όταν/αν/ότι, артикли.

> Цель ученика — A2 для гражданства Кипра (отдельный кипрский экзамен уровня A2).
> Этот A1-фундамент — обязательная база под него.

**Честные оговорки:**
- Словарь (402) — это ~¼ официального A1-ядра. Идёт планомерное расширение
  партиями строго по глоссарию ΚΕΓ (цель ~800).
- 100% покрытие *всего* словаря дают только секции, чья задача — словарь:
  **Темы, Повтор (SRS), тренировки тем, Чтение**. Грамматика и письмо —
  навыковые секции на репрезентативной выборке (не «весь словарь»).
- Экзамен по лексике/аудио и «текст из слов» — это выборка из всего словаря
  (любое слово достижимо, но за один заход тестируется часть, не всё).
