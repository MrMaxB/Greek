# Методология и покрытие

> Обновляется при апдейтах. Цифры пересчитываются: `python3 tools/coverage.py`.
> Тесты целостности: `node tools/test.js`.

## Методология (синтез из исследований + CEFR)

1. **Алфавит → звук** в первую очередь.
2. **Интервальные повторения (SRS, SM-2)** — ядро удержания словаря.
3. **Понятный ввод** — graded-тексты A0→A1 с тап-переводом любого слова.
4. **Продукция** — письмо (конструктор/пропуски/текст-из-слов/о-себе/свободное),
   говорение (фразы вслух + открытый вопрос-ответ), упражнения по грамматике
   с режимом **свободного ввода** (вспоминание, не узнавание).
5. **4 навыка** + пробные экзамены формата ΚΕΓ.
6. **Работа над ошибками** — промахи из упражнений/экзаменов идут в отдельный
   спейс-повтор.
7. **Настройки**: скрытие транскрипции (формирует чтение), ввод vs выбор.

## Честные оговорки
- **Официальный A1 закрыт на 88% словарём / 93% со всем контентом.** Добраны
  реальные пропуски: базовые цвета (κόκκινος, μαύρος…), числа 8/9 (οκτώ, εννέα),
  профессии (παιδίατρος, χειρουργός…), еда, бытовые слова, техника (κινητό, ίντερνετ).
  Раньше они «не считались» из-за форм (цвет хранился в ср.р., число — в разг. форме).
- **Остаются непокрытыми ~7% (≈85 лемм):** женские формы прилагательных-
  национальностей (αγγλική при наличии αγγλικός), узкие грамматические мета-термины
  глоссария (ενικός/πληθυντικός/συνώνυμο) и совсем редкое. Это сознательный отказ —
  не ядро A1 для разговора и письма.
- **Синергия 93%** (было 100% на 1071 слове; просела при добавлении 239 новых,
  затем восстановлена конструктором предложений). Оставшиеся ~88 осиротевших —
  те же мета-термины и национальности; они всё равно прогоняются через SRS и
  тренировки тем. Метрика считает только статический текст.
- Словарь проверен: транскрипции нормализованы (греч.→кир. со стрессами),
  дубли подсказок в письме отсутствуют.
