# Ελληνικά A1 — интерактивный тренажёр греческого

Тренажёр-симулятор для изучения греческого **с нуля до уровня A1** — как фундамент
для экзамена **A2** (требование для гражданства Кипра, проводит Минобразования Кипра
раз в год, обычно в мае; проверяются 4 навыка: аудирование, чтение, письмо, говорение).

Интерфейс на русском. Полностью офлайн, без установки и без зависимостей —
один HTML-файл и немного JS. Прогресс хранится в браузере.

## Как запустить

Просто открой `index.html` в браузере (двойной клик). Работает и на телефоне,
и на компьютере. Ничего ставить не нужно.

### Открыть с телефона (без установки)

Открой эту ссылку в браузере телефона (отдаёт файлы из ветки напрямую):

**https://raw.githack.com/MrMaxB/Greek/claude/greek-a1-trainer-EQevi/index.html**

Чтобы пользоваться как приложением — в браузере телефона нажми «Поделиться» →
«На экран Домой». Иконка появится как у обычного приложения, откроется на весь
экран. Прогресс хранится прямо на телефоне.

Для озвучки греческого используется встроенный в браузер синтез речи
(Web Speech API). Лучше всего работает в **Chrome / Edge**. Если греческого
голоса нет — приложение об этом скажет; весь остальной функционал работает.

## Методология (на основе ресёрча)

1. **Алфавит в первую очередь.** Греческое письмо — главный барьер. Учим
   узнавание букв и буквосочетаний (ου, μπ, ντ, αυ, ευ…) визуально + на слух.
2. **Интервальные повторения (SRS).** Ядро словаря по упрощённому алгоритму
   SM‑2: слова возвращаются ровно тогда, когда начинаешь забывать. 10–15 минут
   в день эффективнее редких марафонов.
3. **Понятный ввод + активный отзыв** через все навыки: слушать (озвучка),
   читать, выбирать перевод, печатать по‑гречески.
4. **Тематические модули** по бытовым темам экзамена A2.

## Что внутри

- 🔤 **Алфавит** — 24 буквы с произношением и примерами + буквосочетания; тренажёр «буква → звук».
- 🧠 **Повторение (SRS)** — умные карточки по всему словарю с оценкой запоминания.
- 📚 **Темы** (12 наборов, 175 слов) — каждый со списком и 5 режимами: карточки, выбор перевода, аудирование, набор по‑гречески и **🎧 диктант** (слышишь слово — записываешь его). Есть экранная греческая клавиатура и сверка без учёта ударений.
- 📖 **Мини‑грамматика A1** — роды и артикли, глагол «быть», настоящее время, ударение, знаки препинания.
- 📊 **Прогресс** — стрик, освоено слов, закреплено, календарь активности за 14 дней.

### Темы словаря
Приветствия · Числа · О себе · Семья · Время/дни/месяцы · Еда · Город ·
Покупки · Глаголы · Прилагательные · Вопросы/местоимения · Полезные фразы.

## Структура

```
index.html        — оболочка
css/styles.css     — стили (мобайл-фёрст, греческая бело-синяя тема)
js/data.js         — весь учебный контент (алфавит, словарь, грамматика)
js/srs.js          — движок интервальных повторений + статистика
js/speech.js       — озвучка через Web Speech API
js/app.js          — роутер и все режимы тренировки
```

## Дальше (идеи для развития до A2)

- Расширить словарь до ~600–800 слов и добавить уровень A2.
- Диалоги-сценарии (в кафе, в банке, у врача) для аудирования.
- Тренажёр спряжения глаголов и склонения по падежам.
- Письменные задания формата экзамена (заполнить форму, короткое письмо).
